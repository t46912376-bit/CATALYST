# ⚡ CATALYST

### *The Steam Library of Hacking Tools*

CATALYST is an open-source Python-based security toolkit launcher designed to bring a collection of tools together in one place.

Instead of digging through folders and launching individual programs, CATALYST gives you a single interface for organizing, launching, and managing your toolkit — with a UI designed to feel like something straight out of a hacker movie.

> **One launcher. Multiple tools. One interface.**

---

## ✨ Features

### 🧰 Custom Tools

Add your own tools and utilities to CATALYST and launch them directly from the interface.

### 📂 Organized Tabs

Different categories and tabs make it easier to find exactly what you're looking for without digging through folders.

### 🖥️ Hacker-Style UI

A terminal-inspired interface with system diagnostics, boot sequences, status indicators, and a cinematic aesthetic.

### ⚡ Built-In Commands

CATALYST comes with a selection of simple commands pre-installed so you can start using the environment immediately.

### 🧩 Expandable

The project is designed around adding more tools and functionality over time.

### 🐍 Python Powered

Built entirely with Python, making CATALYST easy to modify, experiment with, and extend.

### 🔓 Open Source

The source code is available for anyone to inspect, modify, improve, and contribute to.

## 🚀 Getting Started

### Option 1 — Prebuilt EXE

Download the latest CATALYST build from Google Drive:

**Google Drive:**
https://drive.google.com/file/d/1Lxr_1zexETVLSWexZB8ikJopYFfnH6aF/view?usp=sharing

Extract the downloaded files and launch:

```text
CATALYST.exe
```

No manual Python setup should be required when using the packaged release.

The software may be flagged as a virus, this is due to it coming with LOIC and HOIC, just add the file to your exclusions.

---

### Option 2 — Run From Source

Clone the repository:

```bash
git clone https://github.com/t46912376/CATALYST.git
cd CATALYST
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Then launch:

```bash
python launcher.py
```

## 🔌 Adding Tools

CATALYST is designed to be expandable.

You can add compatible utilities to the appropriate tool directory and configure them through the launcher.

The goal is to make adding new tools feel more like installing another application into a game library than manually managing a collection of executables.
